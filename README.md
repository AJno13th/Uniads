# UNIADS Educational Consulting

Official website for **Uniads.co.uk** — UK educational consultancy helping students with university applications, course matching, student finance, childcare grants, and related support.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Key pages

- `/` — Home
- `/services` — Services hub
- `/courses` — Courses & partner universities
- `/about` — About UNIADS
- `/apply` — Application form (dropdowns + checkboxes)
- `/book` — Phone consultation calendar
- `/privacy-policy` — Privacy policy (footer)
